# User Database Web Page

This project is a small web page that lets users submit a name and age, stores the data in a MySQL database, and displays the saved records in a table on the same page.

Page: https://mohamed-elbagir.free.je/user.html

## user.html

The frontend page where the user enters `name` and `age`. The layout centers the elements and uses a dark theme. The form data is sent without leaving the page, and the table updates live.

JavaScript is used to load table data from `in.php`, render the table rows on the page, submit new users without a page reload, clear input fields after successful submission, display a temporary status message, and send toggle requests to update a user status. The status messages are generated by the PHP file.

## in.php

The backend code that connects to the MySQL database. SQL `INSERT` and `SELECT` are both used in this file. `INSERT` is used to add new data to the database. `SELECT` checks whether the submitted name and age already exist in the database, and a status message appears indicating the result. It also returns the current user records ordered by `id` ascending. In addition, the file handles the action to toggle status between `0` and `1`, and it normalizes the name formatting by capitalizing the first letter and making the rest lowercase. Status messages are generated here and used by `user.html` to display them using JavaScript.

## Status Messages

Status updated successfully.
- Returned when the backend successfully toggles a user record’s status value.

Error updating status: ...
- Returned when the toggle update query fails and the database reports an error.

This user already exists.
- Returned when the submitted name and age combination already exists in the user table.

New record created successfully.
- Returned when a new user record is inserted successfully.

Error: ...
- Returned when the insert query fails and the database reports an error during record creation.

Please enter both name and age.
- Returned when the form is submitted with either name or age missing or empty.
